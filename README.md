# ConflictOracle

Frontend for a GenLayer Intelligent Contract that resolves conflicting observations through validator consensus.

- Network: GenLayer Testnet Bradbury
- Contract: 0x604fF0b501Fb934AD77dA25DD4a7f0617e540Fb6

## Run locally
npm install
npm run dev

Optional: set VITE_CONTRACT_ADDRESS to use another deployment.
Contract source: contracts/conflict_oracle.py
